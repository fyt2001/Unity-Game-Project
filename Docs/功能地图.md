# 功能地图（玩家视角 → 验证脚本）

更新：2026-11-12（Asia/Shanghai）。场景和模块以磁盘为准：`Assets/Scenes` 有 LaunchScene / LoginScene / HomeScene / BattleScene（都在 EditorBuildSettings 里启用），另有 PlaceholderTest（不在构建列表）。

运行方式（都用 Windows PowerShell 5.1 的 `powershell.exe`，不是 pwsh）：

- 纯 Lua 和静态检查：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\verify.ps1 -Fast`
- EditMode 和 Play 冒烟（需要先关闭 Editor）：`... tools\verify.ps1 -Full`
- 单条 harness 脚本：`... tools\game.ps1 script tools\harness_scripts\<name>.json`，结果写到 `Logs\AgentRuns\<时间>_harness_<name>\result.json`，截图放在同一目录

状态说明：

- **通过**：本轮在本机实际跑过并且通过。
- **已写未跑**：脚本或测试已经落地，C# 已通过离线编译检查，但本轮没有在 Unity 里跑。原因是 batchmode 启动时报"本机没有激活的 Unity 许可证"，退出码为 1。
- **隔离**：会运行和报告，但不阻断 verify。
- **未落地**：还没有对应的自动验证。
